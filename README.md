### 📖 درباره کتاب 

کتاب **Operating Systems: Three Easy Pieces (OSTEP) ** یکی از منابع شناخته‌ شده برای یادگیری مفاهیم سیستم‌عامل است. این کتاب موضوعات اصلی سیستم‌ عامل را حول سه مفهوم اساسی بررسی می‌ کند :
- **Virtualization**
- **Concurrency**
- **Persistence**

در طول کتاب مفاهیمی مانند CPU ، Memory ، Process ، Thread ، Scheduling ، Synchronization ، File System ، I/O و بسیاری از مباحث مهم دیگر بررسی می‌ شوند.
